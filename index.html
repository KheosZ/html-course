what is HTML

html short for HyperText Markup Language. consist of a series of elements. for example, the opening paragraph of this journey, the paragraph text is enclosed like this:

<p>"text"</p>

the element above has 3 segments. first the opening tag: <p>, the content: "text", and the closing tag: </p>. element <p> is used when making a new paragraph. Here is the list of all avaiable elements in Html.

another example is the title of this segment. the title is made with Section heading element. and to create a link like before, use Anchor element to create hyperlink to web page, email adresses, or anything that use URL. not all elements in Html has closing tag. this is called Void element. basically the void element doesn't have closing tag like <p> or <a>. further explanasion in the next segment
