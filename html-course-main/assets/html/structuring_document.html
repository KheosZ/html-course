Basic Section of Document

there are few components that shaped webpages together.

    Header
    is a big heading, title or Something at the start of a page.

    Navigation bar
    is some sort of shortcut to navigate through website. like a menu button or link to some section of the website. not a requirement but gonna be super helpful for user when the website is growing big.

    Main content
    this is where the majority content is placed. contating images, text, audio or something. its just the main content of the website.

    Sidebar
    maybe i see it as side content. or almost the same as Navigation Bar. might contains search bar, check box when the website have organized items. or shortcut to popular pages, author biography or even marking each chapter in the pages

    Footer
    usually, its a strip at the bottom of the pages. contains copyright notices, contact info or other secondary information besides the header.
